# App — APK

APK do aplicativo para instalação e avaliação.

## Como baixar
Clique em `app.apk` acima e depois no botão **Download** (ou **View raw**).

## Como instalar no Android
1. Baixe o `app.apk` no celular.
2. Toque no arquivo baixado.
3. Se aparecer aviso, permita "instalar de fontes desconhecidas" para o app usado para abrir.
4. Confirme a instalação.
